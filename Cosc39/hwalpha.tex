\begin{problem}{1} \textbf{Punched-tape machine}

    Punched-tape machine is a Turing machine equipped with an infinite two-way single-row tape, where each cell can be either punched or unpunched. Furthermore, once a cell is punched, it can never be unpunched. Alternatively, a punched-tape machine is just a Turing machine with unary alphabet consisting of a single symbol $\blacksquare$ (together with the empty cell symbol $\square$), where any symbol $\blacksquare$  written on the tape can never be erased. Prove that the punched-tape machine is equivalent in power to the standard Turing machine. In other words, the languages accepted by the punched-tape machines are exactly all the computable languages.
\end{problem}

\begin{solution}
    \bbni

    Let $M$ be a punched-tape machine; our goal is to show that $M$ can simulate a standard Turning machine $M'$ with a two-way infinite tape and the binary alphabet. We assume that $\Sigma' = \{0, 1\}$. Note that the converse holds immediately since every punched-tape machine is already a Turing machine.

    The idea is to main a sequence of encodings $S_0, S_1, S_2, \ldots$ of $M'$ after $k$ steps. Doing this allows us to never have to read or modify a previous encoding, letting us bypass the restriction imposed by the punched-tape machine. 

    \textbf{Data Representation:}

    Each encoding $S_k$ encodes a configuration $(q, \mathsf{tape}, h)$ of $M'$ in two pieces: 
    \begin{enumerate}
        \item A block of $|Q'|$ consecutive cells, where cell $i$ is $\blacksquare$ if and only if the current state is $q_i$. Exactly one cell is $\blacksquare$ in a given encoding.
        \item 
        
        At step $k$, $M'$ head has moved at most $k$ positions in either direction. So for each position $p \in \{-k, \ldots, k\}$  we use three consecutive cells on the punched-tape machine to encode both the tape symbol at $p$ and whether the head is located at $p$. The encoding is as follows:
        \begin{align*}
            \square\,\square\,\square &= (\square,\ \text{head not here}) \\
            \blacksquare\,\square\,\square &= (0,\ \text{head not here}) \\
            \blacksquare\,\blacksquare\,\square &= (1,\ \text{head not here}) \\
            \square\,\square\,\blacksquare &= (\square,\ \text{head here}) \\
            \blacksquare\,\square\,\blacksquare &= (0,\ \text{head here}) \\
            \blacksquare\,\blacksquare\,\blacksquare &= (1,\ \text{head here})
        \end{align*}

    \end{enumerate}


    \textbf{Transition Simulation:}

    We start by encoding $S_0$, i.e. the intial configuration of $M'$, once it's done the head returns to the start of $S_0$. At step $k$, $M$ runs a sub-routine that does the following: 
    \begin{enumerate}
        \item Sweep $S_k$ to find the current state $q$, the head position $h$ (the unique cell in the tape section with third cell $\blacksquare$), and the symbol $a = \mathsf{tape}[h]$.
        \item Apply $\delta'(q, a) = (q', b, \Delta)$, since it is encoded in $S_k$. 
        \item Write $S_{k+1}$ to the fresh tape following $S_k$, we use seven consecutive $\blacksquare$s as delimiters since that is the minimum that cannot naturally occur in any encoding. 
        \begin{itemize}
            \item \textbf{State:} Punch only cell $q'$ to $\blacksquare$.
            \item \textbf{Tape:} For each position $p \in \{-(k+1), \ldots, k+1\}$, copy the symbol from $S_k$ (or $\square$ for the two new boundary positions), writing symbol $b$ at $p = h$ and setting the head marker $\blacksquare$ at $p = h + \Delta$.
        \end{itemize}
        \item Move $M$'s head to the start of $S_{k+1}$ and repeat.
    \end{enumerate}
    $M$ accepts if and only if the state corresponding to $q'$ in $M'$ is an accept state.

    Thus we can simulate a standard Turning machine using a punched-tape machine. 
\end{solution}
